## If the hackathon asks for a live link

You need to deploy the frontend and backend to a public hosting service. The GitHub link alone is not a live demo. Your options are:

- Submit the GitHub link plus the demo video.
- Provide a local-run README.
- Deploy the frontend and backend publicly if time allows.

Because your deadline is close, the safest submission is:

1. Public GitHub repository.
2. Narrated demo video showing the working product.
3. README with exact local setup instructions.
4. Live URL only if you have successfully deployed and tested it.

Do not submit a link such as:

```text
http://localhost:3000
```

as a public demo URL; judges cannot access your computer through it. Public GitHub repositories commonly serve as the code and setup source, while a separately hosted URL is needed for direct browser access. [175][178]
